# Orbit · Money Circlegrams

Visualize San Diego cash flow as circlegrams — compare renting vs buying over 6–60 months.

## Your baseline (editable in the app)

| Source | Default |
| --- | --- |
| VA disability (80%) | $2,400 − $328 recovery |
| School BAH + stipend | $3,800 |
| Job (FOR) | $4,800 |
| Rent scenarios | $2,900 or $3,500 (slider) |
| Buy defaults | VA 0% down · seller credits cover closing · ~$650k SD home |

## Run locally

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

Illustrative planning model only — not financial advice.
