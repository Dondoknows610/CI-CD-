# Orbit · Property Investment & Exit Strategy

Decision engine for evaluating a San Diego property from purchase through post-occupancy exit options.

## Workflow

1. **Select property** — address, price, beds/baths, type, condition, HOA, etc.
2. **Estimate rent** — conservative / expected / optimistic range + manual override
3. **Financial model** — VA loan, taxes, insurance, vacancy, management, cash flow
4. **Occupancy timeline** — configurable months → decision point equity/value
5. **Exit strategies** — rent & hold · sell · refinance · keep existing loan
6. **Recommendation** — ranked with rationale (not a blunt buy/sell)

## Defaults

- VA **0% down**, seller credits covering closing (disability funding fee waived)
- Sample Mission Valley–area condo profile (editable)
- 12-month occupancy decision point (configurable)

## Run

```bash
npm install
npm run dev
```

